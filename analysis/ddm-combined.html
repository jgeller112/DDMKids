Model parameterization

Both groups are modeled with a hierarchical Bayesian drift diffusion model (the Wiener process; Ratcliff, 1978), fit via brms (Bürkner, 2017) through Stan (Carpenter et al., 2017) with the cmdstanr backend. Each trial’s response time and binary choice are decomposed into drift rate (mu), non-decision time (ndt), starting point (bias), and boundary separation (bs).

mu, ndt, bias, and bs each get the full condition * dist * age.group factorial structure, coded as 0 + condition:dist:age.group — one directly-interpretable parameter per condition x dist x age group cell, rather than a main-effects-plus-interactions decomposition. This coding is necessary for a shared prior scale on every coefficient to translate into an equal implied prior on every cell’s mean: a prior-predictive check (posterior draws generated from the prior alone, likelihood switched off) showed that the conventional decomposition gives up to 2.7-fold differences in implied prior SD across cells — systematically tighter for cells reached via fewer summed coefficients — while the cell-means coding used here flattens that to within 5-11%. By-subject random intercepts and slopes for dist are included on mu in both groups ((1 + dist | p | sn)). In the AI group, bs and bias now share that same random-effects structure too (one correlated 6-dimensional block per subject, rather than three independent 2-dimensional ones) — a re-attempt of something that previously produced severe divergences, back when bs and bias lacked the full factorial fixed-effects structure they have now; see ddm-ai.qmd’s Priors section for the convergence diagnostics and an explicit check of how weakly identified the resulting variance/correlation parameters are. The DI group’s bs/bias random effects have not yet been revisited and remain as they were: ndt has no random effects in either group, and DI’s bs/bias don’t either — for ndt, this is a genuine identifiability limit (too few trials per subject per cell to separate its individual differences from mu’s), not merely a missing-fixed-effects-structure issue.

Fixed-effect priors are identical in structure for both groups: normal(0, 1) on every mu and bias coefficient, normal(0.3, 0.1) bounded to [0, min_Y] on every ndt coefficient, normal(2, 1) bounded to [0, Inf) on every bs coefficient (centered near each group’s earlier pooled single-parameter estimate, ~2.6-2.7). bs’s prior needed to be specified explicitly once it got a 0 + ... predictor formula — that coding drops brms’s default positivity constraint on a parameter-less bs, leaving an unbounded flat prior on the coefficients unless one is set, so positivity here is enforced by the prior’s lower bound rather than the (identity) link.

The random-effect SD priors now differ between groups, though: both use normal(0, 0.03) on mu’s by-subject random effects, but only AI additionally has this same 0.03 scale on bs and bias’s random effects (dpar = bs/dpar = bias), since only AI’s bs/bias random effects have been revisited and refit so far. 0.03 is a deliberately tight, project-specific choice, not a field-standard default — see ddm-ai.qmd’s “Justification for the random-effect prior scale” for the full case (sparse per-subject trial counts, this project’s own divergence history, a direct head-to-head test against HDDM’s much wider default priors that reproduces the failure mode in a form Stan’s divergence diagnostic doesn’t catch, and a robustness check showing the substantive results don’t depend on this choice).

normalize_eq_minus_uneq <- function(df) {
  flip <- df$Level1 == "uneq"
  if (any(flip)) {
    new_low <- -df$CI_high[flip]
    new_high <- -df$CI_low[flip]
    df$Difference[flip] <- -df$Difference[flip]
    df$CI_low[flip] <- new_low
    df$CI_high[flip] <- new_high
    tmp <- df$Level1[flip]
    df$Level1[flip] <- df$Level2[flip]
    df$Level2[flip] <- tmp
  }
  df
}

rope_scale <- function(fit, dpar) {
  draws <- posterior_epred(fit, dpar = dpar)
  0.1 * sd(as.vector(draws))
}

filter_row <- function(df, ...) {
  filters <- list(...)
  row <- df
  for (col in names(filters)) row <- row[row[[col]] == filters[[col]], ]
  if (nrow(row) != 1) stop("filter matched ", nrow(row), " rows, expected 1")
  row
}

fmt_contrast <- function(df, ...) {
  row <- filter_row(df, ...)
  sprintf(
    "%s, 95%% CI [%s, %s], *pd* = %s%%",
    insight::format_value(row$Difference),
    insight::format_value(row$CI_low),
    insight::format_value(row$CI_high),
    insight::format_value(row$pd * 100, digits = 1)
  )
}

fmt_mean <- function(df, ...) {
  row <- filter_row(df, ...)
  value_col <- setdiff(names(df), c(names(list(...)), "CI_low", "CI_high", "pd", "ROPE_Percentage"))
  sprintf("%s, 95%% CI [%s, %s]", insight::format_value(row[[value_col]]), insight::format_value(row$CI_low), insight::format_value(row$CI_high))
}

credible_label <- function(df, ..., pd_threshold = 0.975) {
  row <- filter_row(df, ...)
  ci_excludes_zero <- (row$CI_low > 0) || (row$CI_high < 0)
  if (ci_excludes_zero && row$pd > pd_threshold) "credible" else "not credible"
}

count_credible <- function(df, pd_threshold = 0.975) {
  sum((df$CI_low > 0 | df$CI_high < 0) & df$pd > pd_threshold)
}

ddm_formula <- function() {
  brms::bf(
    duration | dec(dec_recode) ~ 0 + condition:dist:age.group +
      (1 + dist | p | sn),
    ndt ~ 0 + condition:dist:age.group,
    bias ~ 0 + condition:dist:age.group +
      (1 + dist | p | sn),
    bs ~ 0 + condition:dist:age.group +
      (1 + dist | p | sn)
  )
}
ddm_prior_informative <- function() {
  brms::prior(normal(0, 1), class = b) +                                      # drift rate (mu) fixed effects
    brms::prior(normal(0.3, 0.1), class = b, dpar = ndt, lb = 0, ub = "min_Y") + # ndt fixed effects
    brms::prior(normal(0, 1), class = b, dpar = bias) +                         # bias, logit scale: 0.5 <-> logit 0
    brms::prior(normal(2, 1), class = b, dpar = bs, lb = 0) +                   # bs fixed effects; centered near the pooled single-parameter fit (~2.6-2.7)
    brms::prior(normal(0, 0.03), class = sd, group = sn, lb = 0) +              # by-subject random effects (mu)
    brms::prior(normal(0, 0.03), class = sd, dpar = bs, group = sn, lb = 0) +   # by-subject random effects (bs) -- same tight scale as mu, made explicit
    brms::prior(normal(0, 0.03), class = sd, dpar = bias, group = sn, lb = 0)   # by-subject random effects (bias, logit scale) -- same tight scale again
}
# Custom starting values, since default inits tend to land somewhere the
# wiener likelihood can't evaluate. Returns a function, as brm(init = ) expects.
ddm_inits <- function(data, prior) {
  sdat <- brms::make_standata(ddm_formula(), family = ddm_family(), data = data, prior = prior)
  function() {
    list(
      b = rnorm(sdat$K, 0, 0.2),
      b_bs = rnorm(sdat$K_bs, 2, 0.3),
      b_ndt = runif(sdat$K_ndt, 0.001, 0.05),
      b_bias = rnorm(sdat$K_bias, 0, 0.1),
      sd_1 = runif(sdat$M_1, 0.05, 0.1),
      z_1 = matrix(rnorm(sdat$M_1 * sdat$N_1, 0, 0.01), sdat$M_1, sdat$N_1),
      L_1 = diag(sdat$M_1)
    )
  }
}

Results

Drift rate. At 4–5 years — the youngest age tested — autonomous (0.11, 95% CI [-0.36, 0.58], pd = 68.0%, not credible) and baseline (0.08, 95% CI [-0.31, 0.47], pd = 65.9%, not credible) show little evidence that children differentiate between equal and unequal outcomes, but the norm condition already does (-0.55, 95% CI [-1.04, -0.07], pd = 98.8%). This pattern persists at 6–7 years: norm remains credible (-1.65, 95% CI [-2.08, -1.21], pd = 100.0%), while autonomous (-0.18, 95% CI [-0.58, 0.22], pd = 81.2%, not credible) and baseline (-0.31, 95% CI [-0.74, 0.12], pd = 92.2%, not credible) remain non-credible. By 8–9 years, credible distinctions are evident in all three conditions: autonomous, -1.16, 95% CI [-1.60, -0.73], pd = 100.0%; baseline, -0.63, 95% CI [-1.04, -0.24], pd = 99.9%; and norm, -3.22, 95% CI [-3.80, -2.67], pd = 100.0%. The emergence of credible effects in the autonomous and baseline conditions at 8–9 years aligns with developmental work suggesting that advantageous inequity aversion typically emerges around this age (Blake & McAuliffe, 2011). Norm’s credibility from the youngest age tested onward suggests that explicit fairness framing does not just pull that sensitivity forward to an intermediate age, but makes it detectable years earlier than it otherwise appears.

Non-decision time. In contrast to drift rate, non-decision time shows little evidence of a systematic equal-vs.-unequal distinction. Credible effects emerge in only 3 of the 9 condition-by-age cells, and these effects differ in direction and do not form a consistent developmental or condition-specific pattern. Thus, there is little indication that the fairness manipulation operates through changes in non-decision processes.

Starting point. Starting-point estimates are also highly similar across conditions (autonomous = 0.56, 95% CI [0.52, 0.60]; baseline = 0.55, 95% CI [0.52, 0.59]; norm = 0.53, 95% CI [0.48, 0.58]), with no credible differences between conditions. Equal-vs.-unequal contrasts in starting-point bias are likewise largely absent, with only 1 of the 9 condition-by-age cells reaching credibility and no clear developmental or condition-specific pattern.

Boundary separation. Unlike starting point, boundary separation shows a clear secondary pattern that tracks condition, and closely tracks drift rate’s own timeline rather than leading or lagging it. Equal-vs.-unequal contrasts are credible in 4 of the 9 condition-by-age cells, uniformly in the direction of wider boundaries on equal-split trials. This pattern is most pronounced in the norm condition, where the contrast is already credible at 4–5 years (0.58, 95% CI [0.05, 1.14], pd = 98.4%) — the same age at which drift rate’s norm contrast first becomes credible — and remains credible through 8–9 years (0.95, 95% CI [0.17, 2.09], pd = 99.3%). The autonomous condition reaches credibility only at 8–9 years (0.57, 95% CI [0.08, 1.14], pd = 98.8%), matching drift rate’s own autonomous timeline, and the baseline condition does not reach credibility at any age tested, even though drift rate’s baseline contrast does become credible at 8–9 years — boundary separation’s credible cells are essentially a subset of drift rate’s, not an independent or earlier-arriving signal. Consistent with this pattern, norm also shows the widest marginal boundary separation of the three conditions (autonomous = 2.63, 95% CI [2.49, 2.78]; baseline = 2.45, 95% CI [2.34, 2.57]; norm = 2.90, 95% CI [2.72, 3.13]). This pattern should be read with more caution than drift rate’s: a formal prior-sensitivity check (ddm-ai.qmd, Priors > Prior sensitivity check) found that 3 of these 4 credible cells lose credibility under a weakly informative random-effect prior, leaving only norm@8-9y, while drift rate’s own findings are comparatively stable under the same check.

Taken together, the effect of the fairness prompt on advantageous inequity aversion is concentrated primarily in drift rate, with boundary separation serving as a secondary, norm-specific locus present on essentially the same timeline as drift rate itself rather than emerging ahead of it — though, unlike drift rate, this secondary role depends substantially on the random-effect prior’s scale (ddm-ai.qmd, Priors > Prior sensitivity check). Starting-point bias and non-decision time show little evidence of systematic involvement. The prompt therefore appears to influence how strongly and how early children accumulate evidence differently for equal versus unequal outcomes, and — specifically under explicit fairness framing, and with the above caveat — how much evidence they require before committing to a response, rather than altering their initial response bias or the time required for perceptual and motor processes.

Results

Drift rate. In contrast to advantageous inequity, children distinguish between equal and disadvantageously unequal outcomes from the youngest age tested, and this distinction is evident regardless of prompt condition. At 4–5 years, credible equal-vs.-unequal differences are already present in the autonomous (-0.67, 95% CI [-1.22, -0.11], pd = 99.1%), baseline (-0.69, 95% CI [-1.10, -0.28], pd = 100.0%), and norm conditions (-0.72, 95% CI [-1.18, -0.27], pd = 99.9%). This pattern generalizes to the other age groups. Thus, unlike advantageous inequity, explicit fairness framing does not appear necessary for the distinction to emerge. Indeed, at 6–7 years the norm condition shows the smallest effect (-0.62, 95% CI [-1.04, -0.22], pd = 99.9%), relative to baseline (-2.17, 95% CI [-2.63, -1.72], pd = 100.0%) and autonomous (-1.53, 95% CI [-2.01, -1.05], pd = 100.0%). This pattern contrasts with advantageous inequity, where the norm condition showed the earliest and strongest differentiation.

Non-decision time. In contrast to drift rate, non-decision time shows no evidence of a systematic equal-vs.-unequal distinction. Credible effects emerge in 0 of the 9 condition-by-age cells, indicating that the disadvantageous-inequity effect is unlikely to reflect differences in perceptual, encoding, or motor processes. This mirrors the pattern observed for advantageous inequity.

Starting point. Starting-point bias showed a more limited developmental effect. Equal-vs.-unequal differences became credible at 6–7 years in the autonomous (0.16, 95% CI [0.01, 0.30], pd = 98.2%) and baseline conditions (0.18, 95% CI [0.04, 0.32], pd = 99.4%) and remained credible at 8–9 years (autonomous: 0.16, 95% CI [0.01, 0.30], pd = 98.2%; baseline: 0.22, 95% CI [0.09, 0.34], pd = 100.0%). No corresponding effect emerged in the norm condition at any age. Despite these within-condition contrasts, overall starting-point estimates were similar across conditions (autonomous = 0.55, 95% CI [0.51, 0.60]; baseline = 0.53, 95% CI [0.49, 0.57]; norm = 0.56, 95% CI [0.52, 0.60]), indicating that the effect was specific to the equal-versus-unequal distinction rather than a general shift in response bias.

Boundary separation. Unlike advantageous inequity, boundary separation shows no reliable pattern in this group. Equal-vs.-unequal contrasts are credible in only 2 of the 9 condition-by-age cells, with no shared age or condition trend linking them. Marginal boundary separation also does not differ credibly across conditions (autonomous = 2.77, 95% CI [2.61, 2.95]; baseline = 2.80, 95% CI [2.66, 2.96]; norm = 2.67, 95% CI [2.53, 2.82]). Pooling across condition and age nonetheless recovers a credible marginal equal-vs.-unequal effect (0.25, 95% CI [0.07, 0.44], pd = 99.6%), suggesting a real but diffuse signal rather than the coherent, condition-specific pattern observed for advantageous inequity.

Taken together, disadvantageous inequity aversion is present from the youngest age tested and is largely independent of experimental framing, with the effect concentrated in drift rate. Starting-point bias shows a secondary role specific to the autonomous and baseline conditions, emerging from 6–7 years onward and absent when children were explicitly prompted to be fair — the opposite pattern from advantageous inequity, where boundary separation, not starting point, carried the secondary effect, and specifically in the norm condition. Non-decision time shows no evidence of involvement in either form of inequity aversion.

Main Effects Summary

Every age, condition, and dist main-effect comparison computed above (all four parameters, both groups), consolidated into one APA-style table rather than scattered across the bullets. A second table below does the same for the cell-level dist x condition x age.group interaction contrasts (the primary results throughout this document). Both are built programmatically from the contrasts_* objects already computed above, so neither can drift out of sync with the prose.

Format. Both tables follow APA table conventions: a numbered, italicized title above the table; horizontal rules only (above the header, below the header, at the bottom) with no vertical rules; the Parameter column grouped with rowspan instead of repeating on every row; group and condition/age labels spelled out and title-cased; and a Note. line below explaining abbreviations. AI and DI each get a spanning two-column header (Estimate [95% CrI], pd) rather than four flat columns repeating “AI”/“DI” in every header.

Color coding. mu and bias estimate cells are shaded by direction, since both share the same sign convention given how dec_recode is coded (dec_recode = 1 = reject boundary): a red cell means the comparison shifts evidence/starting-point toward reject, a green cell means it shifts toward accept. Saturation carries credibility — vivid color means the comparison clears the 95% CrI/pd bar, pale color means it doesn’t. bs and ndt are deliberately left uncolored: neither points toward either response boundary, so an accept/reject color scheme would misrepresent what they measure. Alternating row shading (light gray) is layered underneath for readability and doesn’t override the direction color where one applies.

Both tables are hand-built HTML (<table>/<td>, not knitr::kable()) for the rendered document, with every style — background color, borders, alignment — set directly on the <td>/<th> itself so the styling survives a plain copy-paste as well as it can. Because copy-pasting an HTML table into Word or Google Docs is still not fully reliable (rowspan/colspan handling and cell shading can drop depending on the browser and importer), the same row data is also used to build real, native tables via flextable/officer, written out to ddm-combined-tables.docx — opening or importing that file (Word directly, or Google Docs via Drive upload/Open) preserves merged cells, shading, and borders exactly, with no copy-paste step involved.

fmt_est <- function(x) insight::format_value(x, digits = 2)
fmt_ci <- function(lo, hi) sprintf("[%s, %s]", insight::format_value(lo, digits = 2), insight::format_value(hi, digits = 2))
fmt_pd_pct <- function(pd) sprintf("%s%%", insight::format_value(pd * 100, digits = 1))
is_credible <- function(lo, hi, pd) (lo > 0 | hi < 0) & pd > 0.975

combine_estimate_ci <- function(est, lo, hi) sprintf("%s %s", fmt_est(est), fmt_ci(lo, hi))
combine_pd_credible <- function(pd, lo, hi) {
  pct <- fmt_pd_pct(pd)
  ifelse(is_credible(lo, hi, pd), paste0(pct, " ✓"), pct)
}

# Background color for mu/bias estimate cells only (see prose above for why
# bs/ndt are excluded). Vivid = credible, pale = not; red = reject-ward
# (positive), green = accept-ward (negative). NA = no direction shading
# (the alternating row stripe shows through instead).
cell_bg <- function(difference, lo, hi, pd, dpar) {
  if (!(dpar %in% c("mu", "bias"))) return(NA_character_)
  credible <- is_credible(lo, hi, pd)
  if (difference > 0) {
    if (credible) "#f5b7b1" else "#fdedec"
  } else {
    if (credible) "#a9dfbf" else "#eafaf1"
  }
}

}

# One <td>. A direction color (bg) takes priority over the alternating row
# stripe; top_rule is a full-width black table rule, group_rule a lighter
# separator between parameter blocks.
apa_td <- function(text, align = "center", bg = NA, stripe = FALSE, rowspan = 1, top_rule = FALSE, group_rule = FALSE) {
  style <- sprintf("padding:5px 12px;text-align:%s;", align)
  if (!is.na(bg)) {
    style <- paste0(style, sprintf("background-color:%s;", bg))
  } else if (stripe) {
    style <- paste0(style, sprintf("background-color:%s;", STRIPE_BG))
  }
  if (top_rule) style <- paste0(style, sprintf("border-top:%s;", RULE))
  else if (group_rule) style <- paste0(style, sprintf("border-top:%s;", GROUP_RULE))
  rs <- if (rowspan > 1) sprintf(' rowspan="%d"', rowspan) else ""
  sprintf('<td style="%s"%s>%s</td>', style, rs, esc_html(text))
}

apa_th <- function(text, align = "center", colspan = 1, rowspan = 1, top_rule = FALSE, bottom_rule = FALSE) {
  style <- sprintf("padding:6px 12px;text-align:%s;font-weight:bold;background-color:#eeeeee;", align)
  if (top_rule) style <- paste0(style, sprintf("border-top:%s;", RULE))
  if (bottom_rule) style <- paste0(style, sprintf("border-bottom:%s;", RULE))
  extra <- ""
  if (colspan > 1) extra <- paste0(extra, sprintf(' colspan="%d"', colspan))
  if (rowspan > 1) extra <- paste0(extra, sprintf(' rowspan="%d"', rowspan))
  sprintf('<th style="%s"%s>%s</th>', style, extra, esc_html(text))
}

# Builds a real (native, not pasted-HTML) Word table from an apa_row_tibble()
# data frame, matching the HTML tables' look: two-row spanning header, the
# Parameter column merged vertically per block, a light rule between
# parameter blocks, black rules at the top/header-bottom/table-bottom and no
# vertical rules, alternating row stripe, and mu/bias direction shading
# (same cell_bg() used for the HTML cells) taking priority over the stripe.
build_apa_flextable <- function(df, lead_names) {
  df$stripe <- (seq_len(nrow(df)) %% 2 == 0)
  disp <- tibble::tibble(
    param_label = df$param_label, lead1 = df$lead1, lead2 = df$lead2,
    est_ai = combine_estimate_ci(df$diff_ai, df$cilo_ai, df$cihi_ai),
    pd_ai = combine_pd_credible(df$pd_ai, df$cilo_ai, df$cihi_ai),
    est_di = combine_estimate_ci(df$diff_di, df$cilo_di, df$cihi_di),
    pd_di = combine_pd_credible(df$pd_di, df$cilo_di, df$cihi_di)
  )

  ft <- flextable::flextable(disp)
  ft <- flextable::set_header_labels(ft,
    param_label = lead_names[1], lead1 = lead_names[2], lead2 = lead_names[3],
    est_ai = "Estimate [95% CrI]", pd_ai = "pd", est_di = "Estimate [95% CrI]", pd_di = "pd"
  )
  ft <- flextable::add_header_row(ft, top = TRUE,
    values = c(lead_names[1], lead_names[2], lead_names[3], "AI", "AI", "DI", "DI"))
  ft <- flextable::merge_h(ft, part = "header", i = 1)
  ft <- flextable::merge_v(ft, part = "header", j = 1:3)
  ft <- flextable::merge_v(ft, j = "param_label", part = "body")

  black <- officer::fp_border(color = "black", width = 1.5)
  gray <- officer::fp_border(color = "#bbbbbb", width = 0.75)
  ft <- flextable::border_remove(ft)
  ft <- flextable::hline_top(ft, part = "header", border = black)
  ft <- flextable::hline_bottom(ft, part = "header", border = black)
  ft <- flextable::hline_bottom(ft, part = "body", border = black)
  group_rows <- which(df$group_rule)
  if (length(group_rows) > 0) ft <- flextable::hline(ft, i = group_rows - 1, part = "body", border = gray)

  stripe_rows <- which(df$stripe)
  if (length(stripe_rows) > 0) ft <- flextable::bg(ft, i = stripe_rows, part = "body", bg = STRIPE_BG)
  for (col in c("est_ai", "est_di")) {
    is_ai <- col == "est_ai"
    colors <- mapply(cell_bg,
      if (is_ai) df$diff_ai else df$diff_di, if (is_ai) df$cilo_ai else df$cilo_di,
      if (is_ai) df$cihi_ai else df$cihi_di, if (is_ai) df$pd_ai else df$pd_di, df$param)
    colored <- which(!is.na(colors))
    for (i in colored) ft <- flextable::bg(ft, i = i, j = col, part = "body", bg = colors[i])
  }

  ft <- flextable::align(ft, j = c("param_label", "lead1", "lead2"), align = "left", part = "all")
  ft <- flextable::align(ft, j = c("est_ai", "pd_ai", "est_di", "pd_di"), align = "center", part = "all")
  ft <- flextable::bg(ft, part = "header", bg = "#eeeeee")
  ft <- flextable::bold(ft, part = "header")
  ft <- flextable::font(ft, fontname = "Times New Roman", part = "all")
  ft <- flextable::fontsize(ft, size = 10, part = "all")
  ft <- flextable::padding(ft, padding.top = 3, padding.bottom = 3, padding.left = 8, padding.right = 8, part = "all")
  flextable::autofit(ft)
}

Cross-Group Comparison

Considered together, the two groups indicate that the timing of inequity aversion depends on whose interest is at stake.

Disadvantageous inequity aversion required no prompting. From the youngest age tested (4–5y) through 8–9y, and regardless of whether children were prompted to be fair, told to act autonomously, or given no framing at all, disadvantageous offers were met with credible rejection in every condition. This distinction appears to be present from early childhood and is largely unaffected by experimental framing.

Advantageous inequity aversion followed a slower and more context-dependent trajectory. Left to their own devices (the autonomous and baseline conditions), children did not reliably object to advantageous unfairness until 8–9 years — three to four years later than their objection to disadvantageous unfairness, and consistent with prior developmental work placing advantageous inequity aversion’s spontaneous emergence around that age. An explicit fairness prompt, however, brought this sensitivity forward to 4–5 years, the youngest age tested. Advantageous inequity aversion therefore appears to be present but dormant in younger children, requiring either additional development or explicit framing to become detectable.

This asymmetry is located specifically in drift rate rather than in non-decision time, which carried no reliable signal in either group. Each group additionally recruited one secondary parameter, and the two did not overlap. In the disadvantageous group, starting point shifted credibly in the autonomous and baseline conditions from 6–7 years onward, with no corresponding effect in the advantageous group. In the advantageous group, boundary separation showed a credible secondary pattern in the norm condition — wider boundaries on equal-split trials, present on essentially the same timeline as drift rate itself rather than preceding it, with the autonomous condition showing a smaller version of the same pattern by 8–9 years. Boundary separation’s credible cells were close to a subset of drift rate’s, indicating that this reflects caution and evidence accumulation moving together once fairness was made explicit, rather than an independent or earlier-emerging process. Boundary separation showed no corresponding signal in the disadvantageous group. This asymmetry itself is well supported, but the advantageous group’s boundary-separation finding specifically is more prior-sensitive than its drift-rate finding: a formal check substituting a weakly informative random-effect prior (ddm-ai.qmd, Priors > Prior sensitivity check) left only one of its four credible cells standing, whereas the disadvantageous group’s already-sparse boundary-separation cells were essentially unaffected by the same check. The two forms of inequity aversion are thus asymmetric not only in when they emerge, but in which secondary process — starting point or boundary separation — accompanies drift rate in carrying the effect, with that second half of the asymmetry resting on a less robust footing for the advantageous group.
